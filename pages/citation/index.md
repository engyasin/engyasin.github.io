<br>

Cite any blog post with the following template (in bibtex):
<br>

```latex
@article{yousif22rlbyexample,

  title   = "Robot Learning by Example Blog",
  author  = "Yousif, Yasin",
  journal = "www.rlbyexample.net",
  year    = "2022",
  month   = "September",
  url     = "https://www.rlbyexample.net",
  note    = "Title: Post title",

}
```
