Imitation Learning

Imitation learning is the task of learning a policy from demonstrations. It can be used to learn policies for any task, but it is most commonly applied to control tasks. In this work we focus on inverse reinforcement learning (IRL), which is a special case of imitation learning where the goal is to learn a policy that maximizes the expected reward given some demonstration data.
